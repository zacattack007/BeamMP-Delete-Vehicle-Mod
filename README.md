# BeamMP-Delete-Vehicle-Mod
lets you remove any vehicle in the server whether it was yours or not

INSTALATION

1. download the zip file
2. extract the files and put whats in the server folder in the [your-server-name]/resources/server folder

COMMANDS

/dv [player_id] to delete all of a specific players vehicles

/dv [player_id] [vehicle_id] to delete a specific car that belongs to a specific player
